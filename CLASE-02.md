# Clase 2: Configuración del proyecto

## Objetivo

Crear la base técnica del proyecto con React y Vite usando JavaScript.

## Pasos realizados

1. Crear el proyecto con Vite:
   ```bash
   npm create vite@latest platzi-bnb -- --template react
   cd platzi-bnb
   npm install
   npm run dev
   ```

2. Archivos principales:
   - `src/main.jsx` — Punto de entrada de la aplicación
   - `src/App.jsx` — Componente principal
   - `src/index.css` — Estilos globales

3. Limpiamos `App.jsx` dejando solo la estructura básica

4. Creamos estructura inicial de carpetas:
   ```
   src/
     components/
     data/
     styles/
     App.jsx
     main.jsx
   ```

5. Agregamos estilos base en `index.css`
